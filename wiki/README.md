# {{REPO_NAME}} — the knowledge base

Everything this project claims, with its sources, in one place. Research
accumulates *here as it happens* — a fetched paper, a vendored dataset's
licence, a design decision's evidence — not in chat scrollback that
evaporates when the session ends.

This wiki is published as a GitHub Pages site by
`.github/workflows/pages.yml` (enable once with:
`gh api repos/{owner}/{repo}/pages -X POST -f build_type=workflow`).

## Rules of the house

- **Every claim carries a source.** A statement without one is a TODO,
  not knowledge.
- **Tier honestly** where the project deals in contested material:
  *Established* (peer-reviewed, survey, published ephemeris), *Debated*
  (real scholarship, contested), *Speculative* (one author's
  construction, or our own reading). Adapt the tier names to the domain;
  keep the discipline.
- **Machine data provenance lives in `SECURITY.md`**; the wiki's
  provenance page summarises and defers to it.
- **One page per subject**, indexed here. Deep working notes go to
  `research/` with an audit trail; the wiki page cites them.
