# Dark Factory Digest, week of November 2, 2026

*Order 054 · 2026-11-06 · 4 min · Digest, Briefing*

> Labs and banks still keep a human in the loop, while vendors add automations that learn from outcomes and self-improve.

This digest covers 31 October to 6 November 2026. It rolls up two research briefs (3 and 5 November). The week was quiet. No new framework, spec or security incident was confirmed from a primary source. The main theme: labs and banks still keep a human in the loop for the highest-stakes work, while vendors add tools that let agents improve themselves.

## This week's signals

1. **Anthropic keeps human oversight (TechCrunch, 2 November).** A regulatory filing says Anthropic "may soon reach its internal threshold for dramatically accelerated AI-assisted research." Anthropic does not expect to let Claude build successive frontier models without human supervision. The filing was not opened. This is a secondary report.

2. **Goldman Sachs limits coding tools (The Decoder, 3 November).** The bank reportedly restricted Claude Code and other coding tools to engineers because of productivity and risk concerns. No primary source was found.

3. **Self-improving automations (GitHub changelog, 28 October).** GitHub lists "Copilot Automations now learn from outcomes and self-improve." The changelog shows titles only. It gives no detail on approval gates. This is a direction signal.

4. **One cost figure (TechCrunch, 2 November).** The Y Combinator CEO reportedly spends about $100,000 to $200,000 a year on AI tokens, mostly for coding agents. This is one person's figure. It is not a typical cost.

5. **Unconfirmed items.** An aggregator lists a Google Antigravity plugin that blocks destructive CLI commands, Android Studio support for more than 40 coding agents, and an AWS multi-agent blueprint (1 to 3 November). No primary page confirmed them.

## What it means for the River.io Software Factory

A lab with strong agents still gates its highest-stakes loop with a human. Do the same. Keep CareTime, TimeForCare and MaterialsAndPractices at human-gated autonomy, because they handle regulated data. Treat self-improving automations with care: an automation that edits its own rules can weaken its own checks, so keep specs and test gates read-only for agents. Scope each agent to one repo and one GitHub issue, and set a token cap on each issue. Add no MCP connectors or marketplace plugins, so the factory keeps zero third-party dependencies. Use MeowPassword, weathergalactic and sloth for autonomous-loop tests.
